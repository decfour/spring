# Don't Sell 📉

> 광기와 절망이 공존하는 실시간 모의 투자 커뮤니티.

- 가치투자, 장기투자, 거시적 경제는 필요 없습니다. 
- 모든 것을 걸어 매수하고, 신념을 내다 팝니다. 
- 남의 손절에 웃고, 내 손절에 피눈물을 흘립니다.

## Features

- 💵 회원가입 시 지급받는 가상 자금으로 모의 투자
- 📈 미국 주식 실시간 시세와 차트
- 🛒 가상 매수·매도 및 보유 주식·수익률 확인
- 💬 같은 종목에도 목적에 따라 여러 채팅방을 만드는 실시간 채팅

## Tech Stack (Planned)

| 구분 | 기술 |
| --- | --- |
| 언어 | Java 21 |
| 백엔드 | Spring Boot 4.1.1 · Spring Web MVC |
| 인증·보안 | Spring Security |
| 데이터 접근 | Spring Data JPA |
| 데이터베이스 | PostgreSQL |
| DB 마이그레이션 | Flyway |
| 실시간 통신 | WebSocket |
| 빌드 | Gradle |
