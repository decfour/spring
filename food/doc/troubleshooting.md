# 트러블슈팅

### 재료 이름 중복과 목록 교체

`Olive  Oil`과 `olive oil`은 공백과 대소문자를 정규화하면 같은 이름이다. 동시에 등록해도 한 재료를 공유하도록 DB 고유 제약과 중복 키 처리를 적용했다. 요리와 재료 목록은 한 트랜잭션에서 저장한다. 수정 요청에서 목록을 생략하면 유지하고, 빈 배열을 보내면 모두 지운다.

### 요리 삭제와 공통 재료 보존

요리를 지우면 평가와 재료 연결 행을 외래 키의 `ON DELETE CASCADE`로 정리한다. `material`은 여러 요리에서 공유하므로 남겨둔다. 재료의 수량은 양수로 제한하되, `소금 약간`처럼 수량을 숫자로 표현하기 어려운 경우는 `NULL`을 허용한다.
