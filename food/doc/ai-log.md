# AI 개발 로그

커밋별 작업 범위와 구현 방향을 정한 핵심 프롬프트를 정리한다.

## 01. 핵심 백엔드 API

### 핵심 프롬프트

1. **API 우선 설계**

   서비스 기획서를 바탕으로 API 명세 초안을 작성한다. 인증·인가 정책과 테이블 설계는 구현 전에 검토하고, 승인된 범위를 DB·리포지토리·서비스·컨트롤러 순서로 진행한다.

2. **요리·평가 API 구현**

   회원 인증, 요리 등록·조회·수정·삭제, 평가 기능을 구현한다. 요리와 평가 수정·삭제에는 작성자 권한을 적용한다. 조리 편의성·맛·경제성은 각각 1~5점으로 저장하며, 점수별 표시 문구는 프론트엔드에서 관리한다.

3. **요리와 재료 데이터 모델링**

   공통 재료와 요리별 사용량을 분리하고, 요리 상세에서 재료 목록을 조회할 수 있도록 한다. 요리 등록·수정 요청에 재료 저장을 연결한다. 상품·가격 데이터의 저장 방식은 외부 쇼핑 API 선정 이후에 결정한다.

4. **코드 구조와 테스트 정리**

   백엔드는 계층별로 구성하고 인증 코드는 별도 패키지로 묶는다. 서비스 메서드는 읽기 쉽게 작성한다. 테스트는 핵심 시나리오 위주로 유지하고, 한글 `@DisplayName`으로 각 테스트의 목적을 설명한다.
